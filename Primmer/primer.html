Configuración de TypeScript

Instala Node.js y abre una terminal nueva. Comprueba que Node.js y npm estén disponibles:

node -v
npm -v

Instala TypeScript y verifica la versión:

npm install -g typescript
tsc -v

Si PowerShell bloquea la ejecución de scripts, puedes permitirlos para tu usuario:

Get-ExecutionPolicy
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
