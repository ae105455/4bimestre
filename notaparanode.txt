========================================================
GIT / GITHUB
========================================================

IMPORTANTE:

Guardar el archivo con Ctrl + S NO significa que ya está
guardado en GitHub.

Hay 3 pasos diferentes:

1. Guardar el archivo en VS Code
2. Hacer COMMIT en Git
3. Hacer PUSH hacia GitHub


14. GUARDAR LOS CAMBIOS
--------------------------------------------------------

En VS Code:

Ctrl + S

Esto guarda el archivo en la computadora.


15. COMPROBAR GIT
--------------------------------------------------------

En PowerShell:

git status

Este comando muestra qué archivos cambiaron.


16. AGREGAR LOS CAMBIOS
--------------------------------------------------------

Para agregar todos los archivos:

git add .

Después:

git status

Los archivos deberían aparecer preparados para commit.


17. HACER COMMIT
--------------------------------------------------------

Comando:

git commit -m "Configuracion de TypeScript"

El COMMIT guarda una versión de los cambios en el
historial local de Git.


18. SUBIR LOS CAMBIOS A GITHUB
--------------------------------------------------------

Comando:

git push

Esto envía el commit desde la computadora hacia GitHub.


========================================================
¿CÓMO SÉ QUE YA ESTÁ GUARDADO EN GITHUB?
========================================================

Después de ejecutar:

git push

deberías ver un mensaje parecido a:

Everything up-to-date

o algo parecido a:

[new branch] main -> main

o:

main -> main

Eso significa que GitHub recibió los cambios.


19. COMPROBAR QUE NO QUEDAN CAMBIOS
--------------------------------------------------------

Ejecuta:

git status

Si aparece:

nothing to commit, working tree clean

significa que no tienes cambios pendientes en tu
computadora para guardar en Git.


20. COMPROBACIÓN FINAL
--------------------------------------------------------

Para actualizar y subir cambios:

Ctrl + S

git status

git add .

git commit -m "Actualizacion de TypeScript"

git push

Después:

git status

Debe decir:

nothing to commit, working tree clean
